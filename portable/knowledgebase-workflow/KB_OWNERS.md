Knowledgebase owners map

This file maps KB folders or filename patterns to responsible owners. Use it to route review requests and to notify people when you change hub content.

Format: pattern -> owner (email / GitHub handle)

Examples:

- "📝 Notes/⚙️ Operations/**" -> oncall-team@example.com (@oncall-team)
- "🚀 Projects/grenadianbuzz/**" -> product-team@example.com (@product-team)
- "📚 Reference/**" -> docs@example.com (@docs)
- "📊 Dashboard/**" -> analytics@example.com (@analytics)

Add entries as needed. When in doubt, assign the owner who touches the most files under the pattern.
