# Resume Checklist

Use this checklist before continuing interrupted work.

- Confirm objective and definition of done.
- Read recent task/session records.
- Read `~/.agents/memory/projects/<project>/current.md` and `decisions.md`.
- Read latest project handoff packet under `~/.agents/memory/handoffs/YYYY/MM/`.
- Verify branch, recent commits, and unstaged changes.
- Identify blockers and dependency owners.
- Pick one smallest next executable action.
- Record updated project state and create a new timestamped handoff packet before ending session.
