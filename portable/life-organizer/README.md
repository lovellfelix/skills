# Life Organizer Skill

Portable guide for reviewing Apple reminders, calendar events, notes, and family plans on macOS.

## Quick Start

```bash
bash scripts/apple-calendar.sh today --json
bash scripts/apple-reminders.sh overdue --json
bash scripts/apple-notes-safe.sh read-context
```

## Best Uses

- daily personal review
- family event planning
- reminder cleanup
- linking notes, reminders, and calendar context

See `SKILL.md` for the full workflow and command patterns.
