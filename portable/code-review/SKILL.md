What I do

* Review code for bugs, security issues, and best practice violations
* Auto-detect language (Python, JS, TS, Go, Kotlin) and apply appropriate standards
* Identify OWASP Top 10 security vulnerabilities
* Generate actionable improvement suggestions with severity ratings

When to use me

* Before merging pull requests or committing significant changes
* When security audit of code is needed
* To validate code quality against language-specific standards
* After implementing new features that handle user input or authentication
