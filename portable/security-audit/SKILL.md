What I do

* Scan for hardcoded secrets, API keys, and credentials
* Detect SQL injection and XSS vulnerabilities
* Validate input sanitization and auth patterns
* Audit dependencies for known vulnerabilities (OWASP Top 10)

When to use me

* Before code reviews or deployments
* After adding auth, payment, or user input features
* During regular security audits
* When validating compliance requirements
